# Till Ready

A simple phone app (Android, Chrome) to keep track of genuine supermarket money-off vouchers and their expiry dates.

Status: pilot project. `index.html` is the app (it runs as James's private Claude artifact). Changes arrive as pull requests; after James merges, Claude republishes the artifact from the exact merged file and checks it byte for byte.

## Rules for this repository

This repository is public. It must never contain real voucher numbers, barcodes from real vouchers, photos, screenshots of real vouchers, or any personal information. That applies to code, issues, pull requests, commit messages, screenshots, test data and the deployed site. Test data uses made-up example numbers only.

Changes to `main` arrive only through pull requests, and only the owner merges.
